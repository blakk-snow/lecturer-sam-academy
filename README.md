# Number & Algebra Academy

Free interactive web app for learning Number and Algebra.

## First milestone

A student can open the site, create a local nickname, complete Unit 1 Section 1 (three lessons), practise with misconception feedback, take the section quiz, and see progress persist after refresh.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Progress is stored locally in IndexedDB (Dexie). After the first visit, the PWA can be installed for offline use of the app shell and bundled course content.
