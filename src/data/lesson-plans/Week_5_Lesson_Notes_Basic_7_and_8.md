# Week 5 Lesson Notes — Basic 7 & Basic 8

## 1. Basic 7 Mathematics — Week 5

**Subject:** Mathematics  
**Class:** Basic 7  
**Week:** 5  
**Term:** First Term  
**Strand:** Number  
**Sub-strand:** Number Operations  
**Content Standard:** B7.1.2.2

### Indicators
- **B7.1.2.2.1:** Add and subtract up to four-digit numbers.
- **B7.1.2.2.2:** Multiply or divide multi-digit numbers by 1- and 2-digit numbers.

### Resources
Counters, bundles/loose straws, base-ten cut squares, sticks, place-value chart, number cards.

### Core Competencies
- Critical Thinking and Problem Solving
- Communication and Collaboration
- Personal Development and Leadership

### Key Vocabulary
Addition, subtraction, sum, difference, multiplication, product, division, quotient, dividend, divisor, place value, regrouping.

### Learning Objectives
By the end of the lesson, learners should be able to:
1. Add and subtract numbers up to four digits.
2. Apply place-value and partitioning strategies.
3. Multiply multi-digit numbers by one- and two-digit numbers.
4. Divide multi-digit numbers by one- and two-digit numbers.
5. Solve simple real-life problems involving the four operations.

### Lesson Development

#### Phase 1 — Starter
- Revise place value using a place-value chart.
- Give learners short mental-mathematics questions.
- Ask learners to identify the value of selected digits in four-digit numbers.

#### Phase 2 — Main Activities

**Activity 1: Addition**
- Demonstrate addition of four-digit numbers using place value.
- Allow learners to use counters, straws or place-value materials.
- Emphasise regrouping where necessary.
- Learners solve examples individually and compare answers.

**Activity 2: Subtraction**
- Demonstrate subtraction of four-digit numbers.
- Use concrete materials to illustrate regrouping.
- Learners solve examples and explain their procedures.

**Activity 3: Multiplication**
- Revise multiplication as repeated addition/groups.
- Demonstrate multiplication of a multi-digit number by a one-digit number.
- Extend to multiplication by a two-digit number.
- Learners practise with number cards and written examples.

**Activity 4: Division**
- Demonstrate division as equal sharing/grouping.
- Connect division to multiplication facts.
- Learners solve multi-digit division examples using appropriate procedures.

**Activity 5: Real-Life Application**
Present situations involving money, books, food items or school materials. Learners decide which operation is appropriate, solve the problem, and explain their answers.

#### Phase 3 — Plenary / Reflection
Ask learners:
- What is regrouping?
- How do you know whether to add, subtract, multiply or divide?
- What strategy helped you most today?

### Evaluation
1. 3,426 + 2,315 = ______
2. 8,205 − 3,417 = ______
3. 326 × 14 = ______
4. 1,536 ÷ 12 = ______
5. A school has 864 exercise books to distribute equally among 4 Basic 7 classes. How many exercise books will each class receive?

**Answer:** 864 ÷ 4 = 216. Each class receives **216 exercise books**.

### Homework
1. 4,725 + 2,184 = ______
2. 9,000 − 3,456 = ______
3. 245 × 13 = ______
4. 1,728 ÷ 12 = ______
5. A shop has 36 boxes with 24 pencils in each box. How many pencils are there altogether?

## 2. Basic 8 Mathematics — Week 5

**Subject:** Mathematics  
**Class:** Basic 8  
**Week:** 5  
**Term:** First Term  
**Strand:** Algebra  
**Sub-strand:** Algebraic Expressions  
**Content Standard:** B8.2.2.1  
**Indicator:** B8.2.2.1.1 — Use the distributive property to remove brackets and solve multiplication of binomial expressions.

### Resources
Number cards, algebra cards, board, markers, expression cards.

### Core Competencies
- Critical Thinking and Problem Solving
- Communication and Collaboration
- Creativity and Innovation

### Key Vocabulary
Expression, term, coefficient, variable, constant, bracket, distributive property, binomial, product.

### Learning Objectives
By the end of the lesson, learners should be able to:
1. Identify terms in algebraic expressions.
2. Explain the distributive property.
3. Remove brackets from algebraic expressions.
4. Multiply a binomial by a monomial.
5. Multiply two binomials.
6. Simplify algebraic expressions after expansion.

### Lesson Development

#### Phase 1 — Starter
- Revise multiplication using the distributive property.
- Begin with numerical examples such as:
  - 3(4 + 2)
  - 5(7 − 2)
- Ask learners to explain how multiplication can be distributed across brackets.

#### Phase 2 — Main Activities

**Activity 1: Removing Brackets**
- Introduce the distributive property:
  - `a(b + c) = ab + ac`
  - `a(b − c) = ab − ac`
- Demonstrate several examples.
- Learners expand expressions individually and in pairs.

**Activity 2: Collecting Like Terms**
- Give expressions containing like terms.
- Learners remove brackets and collect like terms.
- Discuss common errors involving signs.

**Activity 3: Multiplying Binomials**
- Demonstrate multiplication of two binomials.
- Explain that each term in the first bracket is multiplied by each term in the second bracket.
- Learners practise using examples such as:
  - `(x + 2)(x + 5)`
  - `(x + 4)(x − 3)`

**Activity 4: Applying the Skill**
Learners work in pairs to expand and simplify algebraic expressions. Selected learners explain their steps to the class.

#### Phase 3 — Plenary / Reflection
Ask:
- What does the distributive property mean?
- Why must every term be multiplied when removing brackets?
- How do signs affect the answer?

### Evaluation
1. `4(x + 3)` = ______
2. `5(y − 2)` = ______
3. `(x + 2)(x + 5)` = ______
4. `(x + 4)(x − 3)` = ______
5. `(a − 2)(a + 6)` = ______

### Homework
Expand and simplify:
1. `3(x + 7)`
2. `6(y − 4)`
3. `(x + 3)(x + 4)`
4. `(x + 5)(x − 2)`
5. `(a − 3)(a + 7)`

## 3. Basic 7 Integrated Science — Week 5

**Subject:** Integrated Science  
**Class:** Basic 7  
**Week:** 5  
**Term:** First Term  
**Strand:** Systems  
**Sub-strand:** The Solar System  
**Content Standard:** B7.3.2.1  
**Indicators:**
- **B7.3.2.1.1:** Identify the inner planets and describe their properties.
- **B7.3.2.1.2:** Describe/relate the movement of planets in the solar system.

### Resources
Pictures/charts of the Sun, Moon, stars and planets; globe/ball models; board; planet cards.

### Core Competencies
- Critical Thinking and Problem Solving
- Communication and Collaboration
- Personal Development and Leadership

### Key Vocabulary
Solar system, planet, Sun, inner planets, Mercury, Venus, Earth, Mars, orbit, rotation, revolution.

### Learning Objectives
By the end of the lesson, learners should be able to:
1. Define the solar system.
2. Identify the inner planets.
3. Arrange the inner planets in the correct order from the Sun.
4. State characteristics of the inner planets.
5. Explain the movement of planets around the Sun.

### Lesson Development

#### Phase 1 — Starter
- Display or describe pictures of the Sun, Moon, stars and planets.
- Ask learners what they already know about the solar system.
- Ask: “Which object do the planets move around?”

#### Phase 2 — Main Activities

**Activity 1: The Solar System**
- Explain the meaning of the solar system.
- Identify the Sun as the central body around which the planets move.
- Learners use planet cards to arrange the planets.

**Activity 2: Inner Planets**
- Introduce the four inner planets:
  1. Mercury
  2. Venus
  3. Earth
  4. Mars
- Discuss observable characteristics of each using available charts or models.
- Learners arrange planet cards in order.

**Activity 3: Movement of Planets**
- Demonstrate planetary movement using a ball/globe and a model of the Sun.
- Explain **orbit**, **rotation** and **revolution**.
- Learners describe how planets move around the Sun.

**Activity 4: Group Task**
In groups, learners arrange planet cards, identify the inner planets and explain the movement of a selected planet.

#### Phase 3 — Plenary / Reflection
Ask:
- What is the solar system?
- Name the four inner planets in order.
- What is an orbit?
- What is revolution?

### Evaluation
1. Define the solar system.
2. Name the four inner planets.
3. Arrange the inner planets in order from the Sun.
4. State one characteristic of Earth.
5. What is revolution?

### Homework
Draw and label the Sun and the four inner planets in their correct order.

## 4. Basic 8 Integrated Science — Week 5

**Subject:** Integrated Science  
**Class:** Basic 8  
**Week:** 5  
**Term:** First Term  
**Strand:** Systems  
**Sub-strand:** Mammalian Tooth  
**Content Standard:** B8.3.1.1

### Indicators
- **B8.3.1.1.1:** Identify parts of mammalian tooth.
- **B8.3.1.1.2:** Discuss functions of different types of teeth: incisors, canines, premolars and molars.

### Resources
Pictures/charts, labelled tooth diagrams, mirror, tooth/jaw model where available.

### Core Competencies
- Critical Thinking and Problem Solving
- Communication and Collaboration
- Personal Development and Leadership

### Key Vocabulary
Tooth, teeth, dentition, crown, root, enamel, dentine, pulp cavity, gum, incisors, canines, premolars, molars.

### Learning Objectives
By the end of the lesson, learners should be able to:
1. Identify the main parts of a mammalian tooth.
2. Describe the functions of the main tooth parts.
3. Identify the four main types of teeth.
4. State the functions of incisors, canines, premolars and molars.
5. Relate the structure of teeth to their functions.

### Lesson Development

#### Phase 1 — Starter
- Ask learners what happens to food when they chew.
- Ask them to identify different teeth using a mirror where appropriate.
- Ask: “Do all teeth have the same shape and function?”

#### Phase 2 — Main Activities

**Activity 1: Parts of a Tooth**
- Display a tooth diagram.
- Identify:
  - Crown
  - Root
  - Enamel
  - Dentine
  - Pulp cavity
  - Gum
- Learners label a diagram.

**Activity 2: Types of Teeth**
Introduce the four main types:
1. Incisors
2. Canines
3. Premolars
4. Molars

**Activity 3: Functions of Teeth**
Discuss:
- **Incisors:** cutting/biting food.
- **Canines:** tearing food.
- **Premolars:** crushing and grinding food.
- **Molars:** grinding food.

**Activity 4: Structure and Function**
Learners examine how the shape and position of each type of tooth relates to its function.

**Activity 5: Feeding Application**
Give learners examples of foods and ask which teeth would be particularly useful in biting, tearing or grinding them.

#### Phase 3 — Plenary / Reflection
Ask:
- What are the main parts of a tooth?
- Name the four types of teeth.
- What is the function of the incisors?
- Which teeth are mainly used for tearing?
- Which teeth grind food?

### Evaluation
1. Name four parts of a mammalian tooth.
2. State the function of the enamel.
3. Name the four types of teeth.
4. State the function of the canines.
5. State the functions of premolars and molars.

### Homework
Draw and label a mammalian tooth. Then write one function each for incisors, canines, premolars and molars.
