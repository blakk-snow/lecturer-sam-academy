# Express integers in a given number of significant and decimal places

## Objectives
- Express integers in a given number of significant and decimal places

## Explanation

*Content standard B8.1.1.1* — Demonstrate understanding and the use of place value for expressing quantities in standard form and rounding numbers and decimals to significant figures and a given number of decimal places
Express integers in a given number of significant and decimal places

## Worked Example
1. Express any given integer to a given number of significant figures. (i) Express 56734 correct to two significant figures as 57000. E.g. 2. Express 975.8674, correct to (i) two decimal places; (ii) three decimal places.
