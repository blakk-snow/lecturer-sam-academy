# Model number quantities more than 1,000,000,000 using graph sheets, isometric pa

## Objectives
- Model number quantities more than 1,000,000,000 using graph sheets, isometric pa

## Explanation

*Content standard B7.1.1.1* — Demonstrate understanding and the use of place value for expressing quantities recorded as base ten numerals as well as rounding these to given decimal places and significant figures.
Model number quantities more than 1,000,000,000 using graph sheets, isometric papers and multi-base blocks
