# Draw in a square grid rectangles and triangles with given dimensions.

## Objectives
- Draw in a square grid rectangles and triangles with given dimensions.

## Explanation

*Content standard B7.3.2.1* — Demonstrate the ability to find the perimeter of plane shapes including circles using the concept of pi (π) to find the circumference of a circle.
Draw in a square grid rectangles and triangles with given dimensions.

## Worked Example
1. (i) Draw a rectangle whose area is twice as large as the one drawn on the grid. (ii) Draw a rectangle which is twice as wide as and one and a half times as long as the one in the grid. E.g. 2. (i) Draw in the dot square grid another triangle whose area is 3 square units. E.g. 3. (i) What is the area of the triangle in the square grid? (ii) How many different triangles which have the same area as the one in the grid can you draw?
