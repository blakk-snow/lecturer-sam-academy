# Multiply, divide and solve story problems

### Q1
type: trueFalse
question: 326 × 14 = 4,564
- [x] True
- [ ] False
explanation: 326 × 14 = 326 × 10 + 326 × 4 = 3,260 + 1,304 = 4,564.
difficulty: medium

### Q2
type: fillBlank
question: 1,536 divided by 12 is ____
answer: 128
accepted: one hundred and twenty eight
explanation: 12 × 128 = 1,536, so 1,536 ÷ 12 = 128.
difficulty: medium

### Q3
type: mcq
question: A school has 864 exercise books to distribute equally among 4 classes. How many books does each class receive?
- [ ] 206
- [x] 216
- [ ] 226
- [ ] 261
explanation: 864 ÷ 4 = 216. Each class receives 216 exercise books.
difficulty: hard

### Q4
type: mcq
question: A shop has 36 boxes with 24 pencils in each box. How many pencils are there altogether?
- [ ] 860
- [x] 864
- [ ] 8640
- [ ] 608
explanation: 36 × 24 = 36 × 20 + 36 × 4 = 720 + 144 = 864 pencils.
difficulty: hard
