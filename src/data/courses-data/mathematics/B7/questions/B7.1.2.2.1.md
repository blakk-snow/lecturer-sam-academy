# Add and subtract four-digit numbers

### Q1
type: mcq
question: What is 3,426 + 2,315?
- [ ] 5,731
- [x] 5,741
- [ ] 5,840
- [ ] 6,741
explanation: Add the thousands (3 + 2 = 5), then the hundreds (4 + 3 = 7), the tens (2 + 1 = 3) and the units (6 + 5 = 11). Regrouping the 11 units gives 5,741.
difficulty: easy
