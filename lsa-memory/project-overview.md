Lecturer Sam Academy (v0.1.0, started Oct 2026) is an installable PWA for Ghanaian JHS teachers/students based on the NaCCA Common Core Programme (Basic 7–9). Originally "Number Academy" (spec preserved in `NUMBER ACADEMY.md` at repo root, untracked).

**Stack:** React 19 + Vite 7, React Router v7, Tailwind CSS v4, Lucide icons; lazy-loaded routes in `src/App.jsx`. Local persistence via Dexie/IndexedDB (`src/db/`) — students, progress, attempts, quiz results, planner data. No backend DB for student data.

**Feature areas:**
- **Course Library (rebuilt Oct 6):** `/course` is a curriculum-driven browser (subject → class → strand → indicator); indicators with content open Notes/Practice/Quiz pages (`LibraryIndicator.jsx`). Content comes from `src/data/courses-data/<subject>/<class>/{notes,questions}/<indicator-code>.md`, compiled by `parse-course-content.mjs` into lazy `src/data/courseLibrary/` modules. Seeded with 197 indicator notes converted from the enriched markdown. Legacy interactive "Number & Algebra" course lives at `/course/legacy` (`LegacyCourse.jsx`) with its units/lessons/questions untouched.
- **Textbooks (added Oct 7):** 19 NaCCA books (English + Maths, B7–9: Learner's Books, Workbooks, Answer Books + maths draft) converted to markdown in `src/data/courses-data/textbooks-and-references/md/` (user-provided; images in `md/images/`, ~8.5 MB). The parser splits them into 262 chapters with per-chapter curriculum codes; `BookReader.jsx` renders them chapter-by-chapter with figures resolved via a Vite image glob (excluded from PWA precache, runtime-cached). Indicator pages cross-link "Taught in" book chapters. Science book conversions not yet present — pipeline auto-ingests when they land. The upstream sources (`.docx`/`.xlsx` + `uploads/` in `textbooks-and-references/`) are gitignored (user's choice, commit 8064a5a); only the `md/` conversions + `md/images/` are committed. `pdf2md.py` in that folder IS tracked (user's commit 96aaaf4).
- Curriculum browser: 49 NaCCA markdown files in `src/data/curriculum/`, parsed by `scripts/parse-curriculum.mjs` into ~600 KB `src/data/curriculumData.js`. Tree: subject (10) → B7/B8/B9 → strand → subStrand → contentStandard → indicator (codes like `B7.1.1.1.1`). Mathematics B8/B9 come from `nacca_maths_ccp_structured_b8_b9.json` (added Oct 6); Creative Arts sources are stubs (0 strands).
- Lesson planner: Planner → Term → Subject → Lesson routes with AI-assisted notes and auto-save.
- **Teaching-method lesson plans (added Oct 7, commit 3b9c0c2):** the user's own 7-step method — EOPT/dictation → correction → objectives → image/video → reading time → discussion/demonstration → assignment (mental-maths variant for Mathematics) — lives as data in `src/data/teachingMethods.js` (wording editable in one file). `generateMethodLessonPlan` grounds plans in curriculum text + indicator notes + the textbook chapter teaching the indicator; lesson notes store `methodId` + `sections[]` (schemaless, no migration). "Plan this lesson" on library indicator pages and book chapters deep-links into the chat lesson-plan flow pre-filled (term/week questions only; ChatContext.startLessonPlanFlow). PlannerLesson renders the 7-step plan and has its own "Generate with method" button.
- **Download PDF (added Oct 7, commit 30ed97e):** lesson notes get a "Download PDF" button via print-to-PDF — `PrintLessonPlan.jsx` renders the same layout (header, context grid, curriculum reference, 7-step method / classic fields); `index.css` print rules hide app chrome and show only the plan. Deliberately avoided a PDF library because HTML→PDF libs break on Tailwind v4's modern color format.
- **How-To guide (added Oct 7, commit 584d35e):** `/help` page (`Help.jsx`) with one expandable section per feature area (Course Library, textbooks, planner, teaching-method plans, timetable, AI assistant, curriculum+scheme, practice+BECE bank, profile/accounts), each with what-it-is + numbered steps + a link into the feature. Entry points: Home card, desktop nav "Help" item, Profile link.
- **Onboarding + grouped navigation (added Oct 7, commit 02342ac):** first-run `Onboarding.jsx` at `/onboarding` (Welcome → About → optional Google sign-in), rendered outside the shell; gated by a Dexie `onboarded` settings flag in `App.jsx` (`GatedApp`), replayable via Settings → "Welcome tour". Flat tabs replaced by 4 groups in `src/components/layout/navGroups.js` (single source of truth): Teacher (Planner/Timetable/Scheme), Library (Curriculum/Notes), Student (Courses/Notes/Practice), Settings (Home/Profile/Progress/Help/Welcome tour). Mobile = 4 bottom tabs with slide-up sub-menu sheet (`BottomNav.jsx` rewrite); desktop = 4 dropdowns in the header. "Notes" maps to the Course Library (`/course`) in both Library and Student; Courses = `/course/legacy`.
- **AI assistant (rebuilt Oct 6, 2026):** shared chat platform (`src/context/ChatContext.jsx`, `src/components/chat/`) — floating launcher panel + full `/ai-assistant` page, one Dexie-persisted thread. Greeting chips start guided flows: create a timetable (AI-generated JSON → saved via `saveTeacherSchedule`), create a lesson plan (drives `usePlannerActions` to build term→class→subject→week plan→topic, then links to the lesson page; can AI-generate the full note), browse sample plans, research mode (OpenRouter web plugin with educational domain filters + source citations). Streaming SSE via pass-through proxies (`server.js`/`api/generate.js` forward arbitrary params). Chat answers are grounded in `curriculumSearch.js` (indicator-code RAG + sample plan/bank title matches). Markdown via react-markdown + remark-gfm + KaTeX.
- **Timetable** (`/timetable`, new Oct 6): per-class weekly grid editor; Firestore (`/users/{uid}/teacher_schedules/sample`) when signed in, Dexie always.
- **Question bank (new Oct 6):** `scripts/parse-question-bank.mjs` parses 66 BECE-style science mock papers (~2,640 MCQs + theory + answer keys) into lazy per-class modules `src/data/questionBank/science/b7|b8|b9.js`; Practice page has a "BECE Question Bank" tab (runner records attempts).
- **Sample lesson plans (new Oct 6):** 4 bundled Week-5 notes parsed into `src/data/sampleLessonPlans.js`; PlannerLesson "Load into this note" button.
- Scheme of Learning page renders `src/data/schemeOfLearning.json` (Maths/Science B7+B8, 2026/2027).
- AI via OpenRouter (gpt-4o-mini default), proxied server-side by `server.js` (dev, port 3001) or `api/generate.js` (Vercel).

**Auth (added Oct 5, completed Oct 6, 2026):** Firebase Google Sign-In popup (`src/firebase.js`, `src/context/AuthContext.jsx`), used only for planner sync — `src/hooks/usePlanner.js` routes to Firestore when signed in, Dexie when not. One-time Dexie→Firestore migration on first sign-in (`src/db/plannerMigration.js`); `AuthContext` owns shared `authError` state and surfaces redirect-flow errors via `getRedirectResult`. Auth UI: desktop header controls (`AppShell.jsx`), Planner-page nudge, and a mobile-friendly "Teacher account" card on Profile. Also syncs a sample teacher schedule to `/users/{uid}/teacher_schedules/sample` (`src/db/teacherSchedule.js`, `src/hooks/useTeacherSchedule.js`). See [[planned-work-oct-2026]] for the roadmap.
